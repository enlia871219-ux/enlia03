ShadeLawcro V1.0

Lawcro V1.0의 기능을 유지하면서 Windows 백그라운드(비활성) 입력 모드를 추가한 프로토타입입니다.

추가 기능
- 비활성(백그라운드) 입력 모드
- 대상 창 제목 지정 / 현재 활성 창 제목 가져오기
- 실제 마우스 커서를 움직이지 않고 대상 창으로 클릭 메시지 전송
- 대상 창 캡처를 이용한 이미지 검색(Windows PrintWindow 지원 범위 내)

주의
- 백그라운드 입력은 대상 프로그램이 Windows 메시지 입력을 지원하는 경우에 동작합니다. DirectX/Raw Input/자체 입력 시스템을 사용하는 프로그램에서는 클릭 또는 화면 캡처가 동작하지 않을 수 있습니다.
- 최소화/가려진 창에서의 이미지 캡처는 프로그램별 지원 차이가 있습니다.
- 게임에서 해당 프로그램을 사용하는 경우 해당 서비스의 운영정책을 확인하세요.

기존 기능
- 녹화/재생/일시정지/단계 이동
- 녹화 시작~중지 사이의 클릭을 하나의 녹화 매크로로 저장
- 녹화 매크로 항목 편집
- 이미지 매크로 편집 및 인식 실패 동작 설정
- 이벤트/실행 로그 및 삭제
- 현재 실행 단계 하이라이트
- 저장하지 않은 변경사항 종료 확인
- JSON 기반 .pchain 저장

빌드
1. build.bat 실행
2. 같은 폴더에 생성되는 ShadeLawcroV1.exe 실행
